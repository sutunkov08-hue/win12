# Windows 12 Concept

Настоящая десктопная программа (не сайт!) — концепт интерфейса «Windows 12» на базе Electron, вдохновлённый Windows 11. Внутри — полноценный рабочий стол с оконным менеджером и **проводником, который работает с реальными файлами и папками вашего компьютера**.

![Технология](https://img.shields.io/badge/Electron-33-47848F) ![Платформа](https://img.shields.io/badge/Windows-10/11-blue)

## Возможности

- 🔷 **Рабочий стол** — обои, значки, контекстное меню (как в Windows)
- 🪟 **Оконный менеджер** — перетаскивание, изменение размера, свернуть/развернуть/закрыть, привязка окон к краям экрана (Snap)
- 📁 **Проводник** — реальная файловая система:
  - вкладки, история назад/вперёд, «вверх», обновление
  - боковая панель: Главная, Документы, Загрузки, Изображения, Музыка, Видео + «Этот компьютер» с дисками и местом на них
  - хлебные крошки (адресная строка), поиск по папке, вид «значки/список»
  - создание папки, переименование, удаление (в корзину или навсегда), копирование, вырезание, вставка
  - открытие текстовых файлов в Блокноте, картинок в Фотографиях, остальных — системными программами Windows
- 🗂 **Меню «Пуск»** — поиск, закреплённые приложения, «Рекомендуем» (свежие файлы с рабочего стола), пользователь, выключение/перезапуск
- 📌 **Панель задач** по центру (стиль Win 11) — запущенные приложения, трей, часы и дата
- 📝 **Блокнот** — открытие/сохранение реальных файлов
- 🖼 **Фотографии** — просмотр картинок
- 🧮 **Калькулятор**
- ⌨️ **Терминал** — dir, cd, echo, mkdir, del, type, start, cls, ver и др.
- ⚙️ **Параметры** — тёмная/светлая тема, 9 цветов акцента, обои (4 градиента + своя картинка)
- ℹ️ **О системе** — окно «winver»

## Запуск (для разработки)

Нужен [Node.js](https://nodejs.org) 18+:

```bash
npm install
npm start
```

## Сборка .exe-установщика

```bash
npm install
npm run dist
```

Готовый установщик появится в папке `dist/` (`Windows 12 Setup 1.0.0.exe`). Также можно собрать портативную версию одной папкой/файлом: `npm run dist-portable`.

Собирайте на Windows 10/11 (или в CI). Иконка, NSIS-настройки и имя ярлыка уже прописаны в `package.json`.

## Тесты

Smoke-тест интерфейса (jsdom, без запуска Electron):

```bash
npm install
npm test
```

## Структура

```
main/main.js       главный процесс Electron + все операции с файлами (IPC)
main/preload.js    безопасный мост (contextBridge) между ОС и интерфейсом
renderer/          интерфейс: рабочий стол, панель задач, «Пуск», окна
renderer/apps.js   приложения: Проводник, Блокнот, Фотографии, Калькулятор, Терминал, Параметры
renderer/app.js    рабочий стол, оконный менеджер, меню «Пуск», панель задач
```
